Reference notes

TIH uses formation. TOOH hours and drillout ft/day use formation plus lateral length. The new drillout rate covers the whole Drill Out phase here; no additional support duration is assumed. Set Production has a fixed target of 24.00 hours. Pre Ops and Post Ops are set to 8.00 hours each, with editable budgets in Job setup. Source tables and allocation details are in How to use.

How to use
  1. All phases appear on one continuous sheet. Use the Input button above the sheet to switch every phase between entering duration and entering End Time. The yellow column is editable; the other time column calculates. Switching preserves complete schedule times. Mixed inputs from an older saved file remain until you switch them together.
  2. Start Time follows the previous row, including the previous phase. A blank or invalid time stops the following schedule until it is filled in.
  3. Choose Major Ops Code, then Desc. Ops fills automatically. You can also choose an Ops code directly to fill its category and description. Existing comments stay intact. Edit comments directly in the Com column.
  4. The Reminders columns hold Logistics Cue and SSHE & V&V notes for each activity. They are editable, saved with the planner and included in CSV exports. WellView copying keeps its original five columns.
  5. Use Show / hide columns to change the visible worksheet fields. Hidden columns are retained in the saved file.
  6. Drag the boundary between named column headers to resize a column. Double-click a boundary to reset its width. Comments automatically wrap and expand to show all text. Column widths are included in Save.
  7. Hover or focus a row number to show its tools. + inserts below; ⧉ duplicates the time, operation, comments and reminders; ↑ / ↓ moves within the same phase; − deletes. Move, duplicate and delete preserve the other activities’ durations and recalculate entered end times where possible. A duplicate has a blank target until you set it or Apply setup. Use Undo to recover any row-tool change. Hover or focus a small control for a tooltip.
  8. Use Copy for WellView and choose a 06:00–06:00 reporting day. Entries are grouped by Start Time and stay whole even when they cross a day boundary. All entries in the preview start selected; uncheck any you do not want to copy, or use the preview’s Select all checkbox. These copy selections do not change the planner.
  9. View Target Attainment in Job Setup & Targets or through the bottom tab to compare your entered schedule with row targets by phase and whole job.
  10. Click Save when finished. Open that downloaded HTML next time. The browser cannot overwrite the file you opened; saved copies carry all edits and operation choices.

No installation, Excel, macros, external libraries, or network connection is needed. Browser drafts are a convenience, not a replacement for saving a file. Your organization may restrict local HTML or downloads.

The hidden workbook columns have been omitted. Row target hours remain editable; setup recalculates phase targets. All six phases and the original operation comments are included.

Target basis & calculation notes

Forecast attainment = target hours ÷ scheduled hours × 100. At 100% the schedule matches the target; above 100% uses less time than budget. These comparisons use your entered durations and end times, not a separate completion status. Job and phase scores use summed hours, not averages of percentages. Missing targets or durations withhold the affected score.

Attainment is shown by phase and whole job. Daily attainment is not calculated. WellView exports still use 06:00–06:00 reporting days. Forecast − target above zero means a projected overrun. Job and phase targets sum row budgets; use Apply setup to redistribute the phase budget after adding or removing work.

Row target = phase target × row example actual hours ÷ phase example actual hours. The example phase actuals are TIH 6.25 h, Drill Out 38.50 h and TOOH 11.25 h. These allocation weights are saved independently of editable actuals, keeping the target fixed as the job changes. Apply setup recalculates targets using those weights; newly inserted rows use their current duration when first allocated. Zero-hour rows receive zero target. Calculations retain eight decimals with the rounding remainder assigned to the last positive-duration row, so row targets reconcile to the phase target. Displayed two-decimal values may sum differently due to rounding.
