Reference notes

TIH uses formation. TOH hours and drillout ft/day use formation plus lateral length. The new drillout rate covers the whole Drill Out phase here; no additional support duration is assumed. Set Production has a fixed target of 24.00 hours. Pre Ops and Post Ops are set to 8.00 hours each, with editable budgets in Job setup. Source tables and allocation details are in How to use.

How to use
  1. Choose the number of wells in Job Setup, then enter a name, formation, lateral length, plug spacing and plug count for each. Rig and Job start apply to the complete job. Newly added wells start with six empty phases. The timeline follows well order with no automatic gaps.
  2. Click a well or phase heading to collapse or expand it. Collapsed activities still count in totals and exports. Use + New phase to append any of the six phase types to a well. Use Clear everything to start blank; confirm the warning and Save the reset planner.
  3. All phases appear on one continuous sheet. Use the Input button above the sheet to switch every phase between entering duration and entering End Time. The yellow column is editable; the other time column calculates. Switching preserves complete schedule times. Mixed inputs from an older saved file remain until you switch them together.
  4. Start Time follows the previous row, including the previous phase. A blank or invalid time stops the following schedule until it is filled in.
  5. Choose Major Ops Code, then Desc. Ops fills automatically. You can also choose an Ops code directly to fill its category and description. Existing comments stay intact. Edit comments directly in the Com column.
  6. The Reminders columns hold Logistics Cue and V&V notes for each activity. They are editable, saved with the planner and included in CSV exports. WellView copying keeps its original five columns.
  7. Use Show / hide columns to change the visible worksheet fields. Hidden columns are retained in the saved file.
  8. Drag the boundary between named column headers to resize a column. Double-click a boundary to reset its width. Comments automatically wrap and expand to show all text. Column widths are included in Save.
  9. Hover or focus the persistent + to show the other row tools. + inserts below; ⧉ duplicates the time, operation, comments and reminders; drag the ⠿ handle to move within the same phase (or focus it and use the arrow keys); − deletes. Move, duplicate and delete preserve the other activities’ durations and recalculate entered end times where possible. A duplicate has a blank target until you set it or Apply setup. Use Undo to recover any row-tool change.
  10. Use Copy for WellView, choose the well, then choose a 06:00–06:00 reporting day. Entries are grouped by Start Time and stay whole even when they cross a day boundary. All entries in the preview start selected; uncheck any you do not want to copy, or use the preview’s Select all checkbox. These copy selections do not change the planner.
  11. View Target Attainment in Job Setup & Targets or through the bottom tab to compare your entered schedule with row targets by phase and whole job.
  12. Click Save when finished. Open that downloaded HTML next time. The browser cannot overwrite the file you opened; saved copies carry all edits and operation choices.

No installation, Excel, macros, external libraries, or network connection is needed. Browser drafts are a convenience, not a replacement for saving a file. Your organization may restrict local HTML or downloads.

The hidden workbook columns have been omitted. Row target hours remain editable; setup recalculates phase targets. Each well can have any of the six standard phase types, including repeated phases as needed.

Target basis & calculation notes

Forecast attainment = target hours ÷ scheduled hours × 100. At 100% the schedule matches the target; above 100% uses less time than budget. These comparisons use your entered durations and end times, not a separate completion status. Job, well and phase scores use summed hours, not averages of percentages. Missing targets or durations withhold the affected score.

Attainment is shown by phase and whole job. Daily attainment is not calculated. WellView exports still use 06:00–06:00 reporting days. Forecast − target above zero means a projected overrun. Job and phase targets sum row budgets; use Apply setup to redistribute the phase budget after adding or removing work.

Drill Out target hours = lateral ft ÷ target ft/day × 24. The rate is selected by formation and lateral-length band. Each well uses its own formation and lateral length. Pre Ops defaults to 8.00 h, Set Production is fixed at 24.00 h, and Post Ops defaults to 8.00 h. Pre Ops and Post Ops budgets can be changed in Job Setup. Added phases use the same target rule for their phase type.

Row target = phase target × row example actual hours ÷ phase example actual hours. These allocation weights are saved independently of editable actuals, keeping the target fixed as the job changes. Apply setup recalculates targets using those weights; newly inserted rows use their current duration when first allocated. Zero-hour rows receive zero target. Calculations retain eight decimals with the rounding remainder assigned to the last positive-duration row, so row targets reconcile to the phase target. Displayed two-decimal values may sum differently due to rounding.

Well details, activities, allocation weights, reminders and collapse settings are included in each saved HTML copy. The browser draft is local to this browser. Clearing the planner removes job data while retaining operation choices and target-reference tables for new planning.

Operation codes were matched to the existing code list using descriptions and comments. The BOP function/pressure test uses TEST_BOP; installation/removal uses NUND_BOP. The source WELLHEAD shell-test entry maps to TEST / PRODUCTION TREE / TEST_PRODTREE. Other rig/tubing operations use WORKOVER codes; the wireline packer entry uses WL_PKR. Original descriptions and source row references are retained in the saved data.
